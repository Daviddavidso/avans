# АВАНС — витрина финансовых продуктов

Витрина партнёрских предложений для клиента **TheGood** (заказ от 13–15.09.2026,
пришёл «с мотива»). 19 офферов в четырёх разделах: займы, дебетовые карты,
кредитные карты, счёт для бизнеса. Каталог правится клиентом через панель
управления — без программиста и без правки файлов.

Дизайн собран по двум референсам, которые прислал клиент:
внешний вид — тёмный [alt-tab](https://daviddavidso.github.io/alt-tab/)
(холст `#0e1014`, плавающая шапка-пилюля, крупная типографика, один синий
акцент), состав блоков и кнопки — [upyour.ru](https://upyour.ru/)
(каталог с поиском и разделами, «как это работает», вопросы).

## Запуск

```bash
php -S 127.0.0.1:4740 -t /Users/openclaw/avans
```

или конфигурация `avans` в `.claude/launch.json` (порт **4740**).
PHP нужен только панели: сама витрина — статика.

## Что где лежит

| Файл | Зачем |
|---|---|
| `index.html` | вся витрина, одна страница |
| `css/style.css` | стили сайта |
| `js/app.js` | каталог, поиск, фильтры, лента логотипов, меню |
| `data.js` | **единственный файл с офферами** — его переписывает панель |
| `fonts/` | Manrope (latin + cyrillic), self-hosted |
| `img/logos/` | 57 логотипов банков и МФО (запас шире каталога) |
| `panel.html` + `panel-*.js` + `gate.js` + `publish.js` | панель управления |
| `api.php` | бэкенд панели: вход, сохранение, откат, смена пароля, ZIP |
| `data.php`, `check.php` | выдача каталога мимо кеша и страница проверки для клиента |
| `deploy.sh` | заливка на хостинг по FTP |

## Панель управления

`/panel.html`, пароль — в `.pass-note` (в git не попадает).
Клиент меняет: тексты первого экрана, дату проверки условий, ник Telegram,
разделы и подписи кнопок, карточки (компания, тип, название, крупная строка,
условия парами, партнёрская ссылка, логотип — готовый или свой файл),
порядок карточек, скрытие карточки. Кнопка «Сохранить на сайт» переписывает
`data.js`, прежняя версия остаётся рядом (`data.js.prev`, откат из панели).

Без PHP (например, на GitHub Pages) панель сама уходит в режим черновика:
правки живут в браузере, «Сохранить на сайт» недоступно — это норма.

## Маркировка рекламы

У ссылок u-cpa в адресе есть `erid` — сайт печатает под кнопкой
«Реклама. erid: …» автоматически. У ссылок rko-group `erid` нет, поэтому
и строки нет: выдумывать её нельзя.

## Цифры в карточках

В карточках намеренно **нет придуманных сумм, ставок и сроков** — только то,
что прислал клиент (например «120 дней без процентов» у Уралсиба) и
нейтральные условия оформления. Свои цифры клиент проставляет в панели,
поле «Условия», по данным партнёрки: за недостоверную рекламу отвечает
владелец сайта.

## Где сайт живёт

* Боевой: **https://moneyforeveryone.ru** — хостинг reg.ru, папка `/www/moneyforeveryone.ru`,
  панель на `/panel.html`, самопроверка для клиента на `/check.php`.
  Сертификат уже был на домене, `.htaccess` уводит весь трафик на https.
* Превью для показа: **https://daviddavidso.github.io/avans/** — там нет PHP,
  поэтому панель уходит в режим черновика и не сохраняет. Это норма.

## Деплой

Доступы клиента — в `~/.avans-ftp` (chmod 600), в гит не попадают.

```bash
bash deploy.sh              # сайт без каталога
bash deploy.sh --with-data  # вместе с data.js (затрёт правки клиента)
```

Скрипт заодно ставит права 664 на `data.js`, `index.html`, `panel.html`
(иначе панель не сможет сохранять) и проверяет живой сайт.

## Чего ещё ждём от клиента

* подтверждённые партнёркой суммы, ставки и сроки — если нужны цифры в карточках;
* ник в Telegram для кнопки «Написать в Telegram» (пока пусто — кнопка скрыта);
* решение по названию: «АВАНС» придумано нами, переименовать можно в панели.

Пока клиент не подтвердил название и наполнение, в `index.html` стоит
`noindex` — поисковики сайт не показывают. Снять — убрать строку
`<meta name="robots" content="noindex, nofollow">` и перезалить.
